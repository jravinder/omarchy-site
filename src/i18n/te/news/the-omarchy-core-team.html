Omarchy విపరీతంగా పెరుగుతున్నందున, స్పష్టమైన బాధ్యతలతో కూడిన బృందాలు అవసరమయ్యాయి. Omarchy Core బృందాన్ని ఏర్పాటు చేయడంతో మొదలుపెడుతున్నాం. మా డిస్ట్రో దిశను నిర్ణయించడం, ఎప్పటికప్పుడు ముందుకు సాగేలా చూడటం, ఇతర కంట్రిబ్యూటర్లకు సాయం చేయడం వంటి బాధ్యతలను ఈ బృందం పంచుకుంటుంది.

మొదటి Core బృందాన్ని పరిచయం చేస్తాను:

Ryan Hughes మొదటి రోజు నుంచీ Omarchyలో నాకు కుడిభుజంగా ఉన్నారు. తొలినాళ్లలో తెల్లవారుజామున 3 గంటలకు ఎదురైన అత్యవసర AUR అంతరాయాలను కలిసి ఎదుర్కొన్నాం. మా సొంత ప్యాకేజీ రిపాజిటరీని నిర్మించాలనే ప్రణాళికను కలిసి వేశాం. ఇన్‌స్టాలేషన్, ప్యాకేజింగ్, హార్డ్‌వేర్ సపోర్ట్, గేమింగ్, థీమ్‌లు, CLI టూల్స్, ఇప్పుడు Quattro వరకు — డిస్ట్రోలోని ప్రతి స్థాయిలో Ryan కృషి ఉంది. Quickshellకి మారడం, ప్లగిన్ వ్యవస్థ, జాగ్రత్తగా అమర్చిన Linux సెటప్‌గా ఉన్న Omarchyని పూర్తి ఆపరేటింగ్ సిస్టమ్‌గా మార్చిన మౌలిక సదుపాయాల్లో చాలా భాగం — ఇవన్నీ ముందుకు సాగడంలో ఆయన కీలకంగా సాయపడ్డారు. Omarchyపై పనిచేయని సమయంలో Ryan, Oodleలో భాగస్వామి.

Tobi Lütke నా రెండు Core బృందాల్లోనూ ఉన్న ఏకైక వ్యక్తి! 2004లో మొదలైన తొలి Rails Core Team సభ్యుడిగా, ఆయన ఆ ఫ్రేమ్‌వర్క్‌కు ఎంతో విశేషమైన కృషి చేయడంతో పాటు Liquid, Delayed Job, Active Merchantలను రూపొందించారు. ఆ పని చివరికి Shopify అనే చిన్న కంపెనీగా మారింది — దాని గురించి విన్నారా? ఇప్పుడు try, Omasnap, Wi-Fi QR కోడ్‌లు, Quake తరహా ఏజెంట్ కన్సోల్ వంటి ప్రాజెక్ట్‌లతో Omarchyకి విస్తృతంగా సహకరిస్తున్నారు. IMSAలో రేస్ చేసే #11 Shopify Racing LMP2 కారులో ఆయన నా సహ డ్రైవర్ కూడా.

Bjarne Øverli, Unite AS CTO. Omarchyతో అందించే విజువల్ థీమ్ బిల్డర్ Aetherని, మా TUI ఆధారిత మ్యూజిక్ ప్లేయర్ cliampని రూపొందించింది ఆయనే. కొన్ని కాన్ఫిగరేషన్ ఫైళ్ల సమాహారంగా ఉన్న మా థీమ్ వ్యవస్థను మరింత క్రమబద్ధంగా మార్చడంలో ఆయన సాయపడ్డారు. రంగులను వాటి ఉపయోగాన్ని బట్టి నిర్వచించడం, Neovim, VS Code, btop, మిగిలిన సాఫ్ట్‌వేర్ అంతటా థీమ్‌లను రూపొందించడం అందులో భాగం. Ethereal, Hackerman, Lupine వంటి థీమ్‌లు కూడా ఆయన సృష్టించినవే. ప్రోగ్రామర్‌గా క్రమశిక్షణ, రూపకల్పనలో మంచి అభిరుచి — ఈ అరుదైన కలయిక Bjarneలో ఉంది. అది Omarchyకి సరిగ్గా సరిపోతుంది.

HANCORE ఒక మెకానికల్ ఇంజినీర్. అనుకోకుండా Omarchy కమ్యూనిటీ రూపాన్ని తీర్చిదిద్దే ప్రధాన వ్యక్తుల్లో ఒకరయ్యారు. ఆయన లెక్కలేనన్ని థీమ్‌లు రూపొందించారు. Omarchyలో డిఫాల్ట్‌గా వచ్చే Last Horizon, Solitude కూడా వాటిలో ఉన్నాయి. ఇప్పుడు Quattro చుట్టూ ఉన్న ప్లగిన్ వ్యవస్థను చూసుకోవడంలో సాయపడుతున్నారు. కంప్యూటర్ ఉపయోగకరంగా ఉండటంతో పాటు అందంగా కూడా ఉండాలని Omarchy ఎప్పుడూ నమ్మింది. దాదాపు అందరికంటే ఎక్కువగా HANCORE ఆ ఆలోచనను ముందుకు తీసుకెళ్లారు.

Spencer Bull, Dellలో Distinguished Engineer. Linux క్లయింట్ సపోర్ట్, AI, ప్లాట్‌ఫార్మ్ సాఫ్ట్‌వేర్‌పై పనిచేస్తున్నారు. సరికొత్త హార్డ్‌వేర్‌తో వచ్చే చిక్కులను ఎదుర్కోవడంలో ఆయన మాకు వారధిగా నిలిచారు. Linux సపోర్ట్‌లో సాధారణంగా వచ్చే ఆలస్యం రాకముందే Panther Lake, తాజా XPS కంప్యూటర్లపై Omarchy సరిగ్గా పనిచేసేలా సాయపడ్డారు. కెర్నల్ సమస్యలు, డ్రైవర్లు, డిస్‌ప్లేలు, Wi-Fi, స్పీకర్లు, పవర్ మేనేజ్‌మెంట్ — సాఫ్ట్‌వేర్ భౌతిక హార్డ్‌వేర్‌ను కలిసే స్థాయిలో Spencer పనిచేస్తారు. అలాంటి నైపుణ్యం Core బృందంలో ఉండటం అమూల్యం.

ఈ ఐదుగురూ ఇప్పటికే ఈ పని చేస్తున్నారు. ఇప్పుడు దాన్ని అధికారికం చేస్తున్నామంతే. నాతో కలిపి, ఇది అద్భుతమైన తొలి Core బృందం. అయితే ఇదొక్కటే బృందంగా ఉండబోదు. Omarchy Rangers ప్రకటన కోసం ఎదురుచూడండి!
